## Worth doing

1. **Positions keep no pawn counts.** `ends_game` and `pawns` scan the 49 cells on every call, and a search calls them for every position. Step 9 took the two biggest costs away (`play_legal`, and the pawn numbers as constants: 28% faster); counting pawns in `Position` itself would save more.
   *When:* only if we come back to MCTS with smarter or shorter playouts (not planned). Step 10 showed that speed is not what holds plain MCTS back: random playouts barely see who is ahead, so twice as many would not help much (see `docs/agents/mcts.md`).

2. **A heavy agent may make the window stutter.** The agent thread and the drawing share one Python interpreter (the GIL).
   *When:* now, by eye: the tests run with no real screen, so only a real window can show it. Watch `Deepening:2s` against itself and look at whether the microbes keep wobbling smoothly while an agent thinks. If they stutter, run the agent in its own process.
